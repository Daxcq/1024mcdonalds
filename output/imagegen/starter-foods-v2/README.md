# 像素快餐基础素材 v2

通过用户指定的 gpt-image-2-vip API 生成，再进行像素网格、色阶、描边、背景和排版整理。此包为水平侧视素材，不包含厨房场景。

## 文件

- food-sheet-magenta.png：1024 × 1024，纯 #FF00FF 背景，4 × 4 排列。
- food-sheet-transparent.png：同样大小，透明背景，透明度只有 0 和 255。
- food-sheet-logical.png：256 × 256 原始逻辑像素图，每格 64 × 64。
- sprites/：16 个独立素材，各有 64 × 64 和 256 × 256 两种版本，保留统一单元格。
- sprites.json：素材名称、顺序和逻辑图中的裁切坐标，放大版本坐标乘以 4。
- generation.prompt.txt：实际用于最终版本的生图提示词。
- verification.json：尺寸、像素放大、背景、描边、色阶与间距的检查结果。

## 从左到右、从上到下的顺序

1. 面包上层、面包下层、牛肉饼、鸡肉饼。
2. 芝士片、生菜、番茄片、酸黄瓜。
3. 洋葱、番茄酱、芥末酱、蛋黄酱。
4. 牛肉汉堡、鸡肉汉堡、薯条、可乐。

## 像素规格

每格 64 × 64 逻辑像素，所有素材共同缩放以保留相对比例。放大版为最近邻 4 倍放大。外轮廓使用 #3A2210；独立食材的主要材质限制为 3 个色阶，芝麻单独保留浅色。完整汉堡包含多种材质。横向相邻素材的最小空隙为较宽素材宽度的 33.3%。无品牌标识、文字、外部投影或半透明边缘。

逻辑图适合导入游戏；放大预览可用于美术确认。游戏引擎中请使用最近邻纹理采样。

## 在本项目继续生图

密钥仅放在项目根目录 .env.imagegen 中；它已被 Git 忽略，且不在此压缩包内。使用 PowerShell，在项目根目录运行：

~~~powershell
.\scripts\generate_image.ps1 -PromptFile .\output\imagegen\starter-foods-v2.prompt.txt -Out .\output\imagegen\next-sheet.raw.png
~~~

入口读取本机配置的服务地址和模型，支持文生图，以及通过 -ReferenceImage 传入参考图的生成方式。支持 API 返回 base64 或图片下载链接；请求成功后先在忽略目录 tmp/imagegen/ 中保存响应，再保存图片。输出文件已存在时会停止，避免覆盖已有成品。

只有采用相同 4 × 4 食材顺序、且四行之间存在完整空白的素材表，才适合使用本项目的 prepare_food_sprites.py 进行批量切分；其他布局需要另行确认裁切位置。
